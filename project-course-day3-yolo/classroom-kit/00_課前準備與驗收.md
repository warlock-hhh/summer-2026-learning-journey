# 課前準備與驗收

## 1. 每台 Raspberry Pi 都要有

將整個 `課堂專案` 複製到學生家目錄，建議改名：

```text
~/opencv-yolo-project/
```

內容必須包含 `images/horse.jpg`、`weights/yolo26n.pt`、`student/`、`teacher/` 與 `requirements.txt`。

## 2. 建立環境

```bash
cd ~/opencv-yolo-project
sudo apt update
sudo apt install -y python3-full python3-venv
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

不要使用 `sudo pip` 或 `--break-system-packages`。

## 3. VS Code

用 VS Code 開啟整個專案資料夾，按 `Ctrl+Shift+P`，選 `Python: Select Interpreter`，指定 `.venv/bin/python`。

## 4. 五道課前驗收

```bash
source .venv/bin/activate
python check_environment.py
python student/step1_opencv_read.py
python student/step2_yolo_inference.py
python teacher/final_project.py
ls -lh outputs/final_result.jpg
```

五道都成功才算完成。另記錄 `final_project.py` 的執行時間，正式上課不做第一次安裝。
