# 學生操作手冊：OpenCV＋YOLO 多物件偵測

## 目標

使用 Raspberry Pi 對 `horse.jpg` 偵測多種物件，輸出類別、信心分數、位置、各類別數量與畫框結果。

## 1. 啟動環境

```bash
cd ~/opencv-yolo-project
source .venv/bin/activate
python check_environment.py
```

## 2. OpenCV 讀圖

```bash
python student/step1_opencv_read.py
```

`image.shape` 的順序是 `(height, width, channels)`。OpenCV 預設色彩順序是 BGR。

## 3. YOLO 推論

```bash
python student/step2_yolo_inference.py
```

每個框包含：

- `class_name`：物件名稱。
- `confidence`：這次預測的把握程度。
- `(x1,y1)`：左上角。
- `(x2,y2)`：右下角。

## 4. 完成分類統計專案

開啟 `student/step3_object_counter_starter.py`，確認四個 TODO：

```python
class_id = int(box.cls.item())
class_name = result.names[class_id]
confidence = float(box.conf.item())
x1, y1, x2, y2 = map(int, box.xyxy[0].tolist())
counts[class_name] += 1
```

使用 `cv2.rectangle()` 畫框、`cv2.putText()` 寫類別與分數、`cv2.imwrite()` 儲存。

執行：

```bash
python student/step3_object_counter_starter.py
```

結果位於 `outputs/student_result.jpg`。

## 5. Threshold 實驗

依序測試 `0.10`、`0.25`、`0.70`。門檻提高通常使框變少：可能減少誤檢，也可能增加漏檢。

## 6. 陌生圖片

將新圖片放進 `images/`，修改 `IMAGE_PATH` 後再執行。比較實際物件與模型輸出。
