## 00:00～00:10　展示成果

展示課本 `horse.jpg` 原圖及完成圖。提問：「圖中有什麼？各在哪裡？各有幾個？」宣布成果：輸出 class、confidence、bounding box、分類數量與結果圖。

## 00:10～00:30　AI、ML、DL

板書 `AI ⊃ Machine Learning ⊃ Deep Learning ⊃ CNN/YOLO`。說明模型從資料調整權重；今天不推導反向傳播。

## 00:30～00:45　訓練與推論

```text
訓練：資料＋標註 → 計算錯誤 → 更新權重
推論：新圖片 → 已訓練權重 → 預測
```

今天只做推論，Raspberry Pi 不更新權重。

## 00:45～01:05　分類、偵測、分割

- Classification：是什麼。
- Detection：是什麼、在哪裡、有幾個。
- Segmentation：每個像素屬於什麼。

修正用語：課本廣稱「物體辨識」，本實作精確稱「物件偵測」；Haar Cascade 是人臉偵測，不是身分識別。

## 01:05～01:30　YOLO

必講：class、confidence、`xyxy`、threshold、IoU、NMS。流程：

```text
圖片縮放 → CNN特徵 → 候選框與類別 → threshold篩選 → NMS → 結果
```

強調 confidence 不是整體 accuracy。
